About This Project

SmartBin AI is an intelligent waste management system powered by machine learning. It analyzes IoT sensor data from smart bins to predict whether garbage collection is required — helping municipalities optimize collection routes and reduce unnecessary operational trips.

🌲
Random Forest Classifier
200 decision trees trained on 1,00,000 real-world waste management records. Achieves 100% accuracy on test data.
📡
6 Sensor Features
Location, Waste Type, Fill Level, Weight, Temperature and Humidity — all collected from IoT-enabled smart bins in real time.
⚡
Real-time Prediction
Sensor data entered instantly predicts collection need — fast and accurate response for every bin location.
🗺️
Smart Priority System
Bins are automatically classified as Critical (96–100%), High (80–95%), Medium, or Low priority based on fill level thresholds.
